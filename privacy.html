Privacy policy: rclone-burak

rclone-burak is a personal backup tool, used only by its owner.

  • It asks for the drive.file scope only. With that scope it can see only files that it created itself.
  • Files go straight from the owner's computer to the owner's Google Drive. No other server is involved.
  • It collects, stores, sells and shares no personal data or usage data.
  • The OAuth token stays only on the owner's computer, in rclone's config file.

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
